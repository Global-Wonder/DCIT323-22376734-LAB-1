# Common Git Commands

| Command | Description |
|---|---|
| git init | Initializes a local repository |
| git status | Shows the status of tracked and untracked files |
| git add . | Stages changes for committing |
| git commit -m "message" | Saves staged changes |
| git log | Displays commit history |
| git push | Uploads commits to GitHub |
| git pull | Retrieves changes from a remote repository |
| git clone | Copies a remote repository locally |
| git remote -v | Displays remote repository URLs |

## Conclusion

Git helps developers track changes and manage different versions of their projects. GitHub provides an online platform for hosting and collaborating on Git repositories.
